# Original-time fragment completion

Status: implemented and protocol-tested on actual legacy/reserved reassembly owners. Source-stable Build41 and all12 selected fragment cases in Cases26 pass, including the four new original-time cases. This is an engineering prerequisite over the existing codec, not an owner-selected wire/default or a complete authenticated fragmentation runtime.

`Reassembler::accept` retains its exact result type and legacy behavior through the same admission core. Additive `accept_at_until(fragment, received, observed, original_cap, output)` reports `TimedReassemblyStatus::{Pending, Duplicate, Expired, Complete}`. Only actual Complete carries `ReassemblyTiming` with read-only first-arrival and effective deadline getters. New expired unique input reports Expired and tombstones the message without writing completed output; existing completion/expiry tombstones remain Duplicate.

The effective cap is the earliest accepted original lifetime/caller cap. Pure parsing precedes monotonic observed-time cleanup. Only valid distinct input passing geometry/duplicate/output preflights may tighten the retained first arrival or deadline; conflict, duplicate and refused completion preserve them. Single-fragment completion returns original timing directly. Legacy existing-message acceptance avoids a fresh observation+lifetime sum, preserving exact near-clock-limit behavior.

The actual Pending backing gains one u64 first-arrival field. Its existing deadline holds the effective cap. `fragment_storage::Plan` and Usage already count the complete actual PendingSlot layout once, with the same3+2R reservations. No second reassembly owner, map or queue is added. Existing logical byte/fragment limits,40-byte LXv1 wire, fragment dimensions, full local message IDs, parser/output ordering and replay-window behavior remain unchanged.

The wire's u64 SessionId is only a caller context label. Each fragment must first pass the maintained enclosing authentication/replay checks, and the caller must retain its complete authenticated Common session/direction/epoch authority independently. This prerequisite does not authorize truncating that authority or treating parsed IDs as authentication.
